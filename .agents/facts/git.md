# Git Facts

- Default branch: `main`. Never commit to it directly.
- Feature branches: `feature/<short-description>`, `fix/<short-description>`, `docs/<short-description>`.
- Pull requests required for every change; start the PR title with the ticket id once the board exists.
- Commits: one coherent change each; stage facts, decisions and changelog with the code they explain.
- Remote: none configured yet. Decision needed: GitHub owner and repository name; the module path in `go.mod` must match.
